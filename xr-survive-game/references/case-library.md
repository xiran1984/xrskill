# 内联案例库

## 案例 1：虚假概念——「我在做个人 IP」

- 用户说：「我在做个人 IP，每天发内容，但感觉没什么进展」
- 五道测试：
  - 投影测试：答「长期来看能变现吧……」→ 🔴（说不清具体路径）
  - 手段-目的：答「失去的是影响力」→ 🔴（影响力是手段，不是生存资源）
  - 信息差：答「我一直在学别人怎么做，还没正式开始变现」→ 🔴
  - 奖励回路：答「上次有满足感是两个月前有一条爆了」→ 🔴
  - 替代性：答「有 1000 万的话……可能不会做」→ 🔴
- 判定：🔴 红灯。「个人 IP」在这里不是目标，是避免谈变现的修辞。真正需要解决的是「怎么用内容直接带来收入」。
- 一句话：「做个人 IP 不是目标，是避免承认自己还没想清楚怎么赚钱的修辞。」

## 案例 2：方向对但执行卡住——「我想健身但坚持不了」

- 用户说：「我想健身，办了卡，但就是不去」
- 五道测试：
  - 投影测试：✅（健康 = 生存资源，身材 = 繁殖竞争力）
  - 手段-目的：✅（知道健身是为了健康和外表）
  - 信息差：✅（没在学健身理论，就是不去）
  - 奖励回路：🔴（从没体验过「练完很爽」的感觉，因为一开始就给自己定了太大目标）
  - 替代性：✅（有钱有伴侣也会健身，为了健康）
- 判定：🟢绿灯。方向真实，是奖励回路断裂 + 启动阻力过大。
- 即刻导航输出：类别 A「穿上跑鞋，走出家门，走 5 分钟就回来」+ 类别 C「在日历上划掉今天，写上『走了 5 分钟』」
- 一句话：「你不是不想健身，是你的大脑从『办卡』到『看到腹肌』之间的奖励回路太长，走不过去。」

## 案例 3：信息差陷阱——「我在学习怎么做电商」

- 用户说：「我在学习怎么做电商，看了很多课和文章」
- 五道测试：
  - 投影测试：✅（电商确实指向生存资源）
  - 手段-目的：🔴（「学习」已经是主要活动，卖货反而成了次要的）
  - 信息差：🔴（学习:执行 = 95:5）
  - 奖励回路：🔴（满足感来自「学到了新知识」，不是「卖出了货」）
  - 替代性：🟡（有钱了可能不做，但不代表这条路错）
- 判定：🟡黄灯。方向本身没错，但用户已经陷入了信息差陷阱——用「正在学习」合理化不执行。
- 切断建议：「停止看任何新课。今天之内，上架一个产品。不需要完美，只需要上架。把学习:执行比从 95:5 拉到 50:50。」
- 一句话：「你买的不是知识，是『正在努力』的幻觉。学完一百节课不如上架一个产品。」

## 案例 4：低能量直接导航

- 用户说：「好无聊，不知道该干什么」
- 不跑模块一。直接进模块二。
- 即刻导航：
  - 动作 1：站起来做 10 个深蹲（类别 A——身体熵减）
  - 动作 2：把手机放到看不见的地方，然后盯着窗外 2 分钟（类别 B + E——切断被动消费，切换感知模式）
  - 动作 3：做完以上两件事后，写下脑子里浮现的第一件想做的小事，然后花 5 分钟做它（类别 C——让奖励回路自己启动）
- 一句话：「先动身体，再动脑子。意识是长在身体上的，不是反过来。」
