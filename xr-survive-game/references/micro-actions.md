# 微动作仓库

从以下六类中各储备若干 5 分钟内可闭环的微动作。每次输出 1–3 个，根据用户当前状态匹配。优先选「做完就能立刻感知到反馈」的动作。

## 类别 A：身体熵减（降低生理混乱度）

| 微动作 | 为什么有效 |
|--------|-----------|
| 站起来，做 10 个深蹲 | 心率↑血氧↑多巴胺↑，直接改变生理状态，不需要任何心理准备 |
| 喝一整杯水（300ml+） | 脱水导致疲劳感，补水是最快的能量恢复 |
| 冷水洗脸 + 30 秒深呼吸 | 激活哺乳动物潜水反射，降低皮质醇 |
| 走到窗口看远处 2 分钟 | 睫状肌放松 + 自然光重置昼夜节律 |
| 伸懒腰 + 扭腰 30 秒 | 释放肌肉张力，解除久坐的生理抑制 |

## 类别 B：环境熵减（降低外部混乱度）

| 微动作 | 为什么有效 |
|--------|-----------|
| 清理桌面上 5 件不属于当前位置的物品 | 视觉噪音↓工作记忆负担↓，启动成本降低 |
| 把手机放到另一个房间或看不见的地方 | 消除最大的注意力切割源 |
| 整理电脑桌面文件到 3 个文件夹 | 数字环境熵减，开机不再面对一片混乱 |
| 把今天要用的一个工具/文件打开并全屏 | 降低启动阻力，准备好了 = 已经开始 |
| 把椅子、屏幕、键盘调整到舒服的位置 | 物理不适是隐性注意力消耗 |

## 类别 C：奖励回路激活（制造一个小闭环）

| 微动作 | 为什么有效 |
|--------|-----------|
| 写下今天只需完成的一件最小任务，完成了就划掉 | 一个闭环 = 一次多巴胺释放，驱动下一个动作 |
| 回复一条你已经拖了超过 24 小时的消息 | 清理认知负债，释放被占用的工作记忆 |
| 把昨天做的一件事写下来（哪怕只是「做了一顿饭」）| 主动识别已完成闭环，对抗「什么都没做」的错觉 |
| 给一个人发一句具体的感谢或赞美 | 社会性奖励激活，被感谢者的正反馈是强效驱动力 |
| 花 2 分钟整理一个数字收藏夹（微信收藏/浏览器书签） | 「整理」是最低门槛的闭环动作，完成感拉满 |

## 类别 D：自动化与系统搭建（一次投入，长期减少摩擦）

| 微动作 | 为什么有效 |
|--------|-----------|
| 把一个重复性操作写成一句话的 checklist | 下次不需要大脑参与决策，直接执行 |
| 关闭手机上 3 个 app 的通知权限 | 每一次通知都是一次注意力劫持 |
| 设置一个 25 分钟的番茄钟，给它起个名字 | 把模糊时间变成有名字的容器 |
| 把一件今天要做的事从脑子倒进手机备忘录/看板 | 释放工作记忆，大脑是用来思考的不是用来记事的 |
| 清理微信/企业微信里 3 个不再活跃的群聊 | 数字社交负债清理 |

## 类别 E：信息摄入切换（从被动消费切换到主动搜索）

| 微动作 | 为什么有效 |
|--------|-----------|
| 把刚才刷的内容用一句话总结写下来 | 被动消费 → 主动加工，激活前额叶 |
| 搜索一个你最近好奇但没查过的具体问题 | 把算法投喂切换为主动狩猎 |
| 关掉推荐流，打开一个搜索框，输入你真正想知道的 | 算法推荐 = 多巴胺劫持，主动搜索 = 目标导向 |
| 把你刚刚看到的某个观点用一句话反驳掉 | 训练怀疑神经回路，打破被动接受模式 |

## 类别 F：社交锚点（用他人存在激活行动）

| 微动作 | 为什么有效 |
|--------|-----------|
| 给一个朋友发「我现在要开始做 X，30 分钟后向你汇报结果」| 公开承诺 → 同侪压力 → 执行力提升 |
| 找一个比你更需要帮助的人，帮他解决一个具体问题 | 阿德勒解法：帮助他人 → 社会认同感 → 打破自卑-不行动循环 |
| 约一个人明天一起吃早饭或喝咖啡 | 锚定一个外部时间点，倒逼今天的行动节奏 |
