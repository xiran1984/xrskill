# xr-survive-game

> 判断一件事值不值得继续；当你卡住或能量很低时，给出一个五分钟内能完成的动作。

## 安装

```text
https://github.com/xiran1984/xrskill，安装其中的 xr-survive-game
```

## 怎么用

```text
/xr-survive-game 我每天都在研究个人 IP，却一直没有实际产出，这件事值得继续吗？
```

## 可以问什么

```text
/xr-survive-game 我是不是在浪费时间？
/xr-survive-game 我不知道现在该做什么。
/xr-survive-game 这件事值得继续吗？
/xr-survive-game 我完全没动力，给我一个五分钟任务。
/xr-survive-game 我一直在学习，却迟迟没有开始做，问题在哪里？
```

它会根据问题进行意义评估、识别手段与目的混淆，或者直接给出一个低阻力微动作。

## 例子

```text
用户：/xr-survive-game 我想做自媒体，但研究了三个月还没发出第一条内容。这件事值得继续吗？

助手：你现在把时间和注意力主要花在自媒体的哪件事上？不用修饰，直接说。

用户：看教程、研究平台规则，还在想自己适合做什么方向。

助手：如果把它说成一句话，自媒体会怎样增加你的收入、技能或关系资源？

用户：我希望以后能靠它赚钱，也想认识一些同行，但现在还没有任何收入。

助手：过去两周，你花在研究上的时间和真正制作内容的时间，大概各占多少？

用户：研究可能占九成，真正制作不到一成。

助手：这说明方向未必是假的，但你很可能陷入了“用继续学习代替进入真实反馈”的信息差陷阱。最近一周，有没有一个具体动作让你产生过“我完成了”的感觉？

用户：没有，我总觉得还没准备好。

助手：目前先判为黄灯：目标可能真实，但奖励回路已经断在“准备”阶段。下一步还要确认替代性测试，再决定是调整方向还是进入五分钟行动。

【对话未结束：Skill 会继续完成判断，并根据结果进入下一轮提问或行动导航。】
```
