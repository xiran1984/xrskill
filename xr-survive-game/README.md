# xr-survive-game

> 判断一件事值不值得继续；当你卡住或能量很低时，给出一个五分钟内能完成的动作。

## 安装

```text
https://github.com/xiran1984/xrskill，安装其中的 xr-survive-game
```

## 怎么用

```text
/xr-survive-game 我每天都在研究个人 IP，却一直没有实际产出，这件事值得继续吗？
```

## 可以问什么

```text
/xr-survive-game 我是不是在浪费时间？
/xr-survive-game 我不知道现在该做什么。
/xr-survive-game 这件事值得继续吗？
/xr-survive-game 我完全没动力，给我一个五分钟任务。
/xr-survive-game 我一直在学习，却迟迟没有开始做，问题在哪里？
```

它会根据问题进行意义评估、识别手段与目的混淆，或者直接给出一个低阻力微动作。

## 例子

问：`/xr-survive-game 我想做自媒体，但研究了三个月还没发出第一条内容。`

答：

```text
当前判断：你卡在“理解自媒体”，而不是“发布内容”。继续收集方法不会带来新的现实反馈。

五分钟动作：
打开备忘录，写下一个你亲自解决过的问题，以及三个解决步骤。

完成标志：得到一段可以直接改成首条内容的文字，不要求发布。
```
