# xr-trauma-support

> 通过低压力对话识别心理卡点，先承接情绪，再寻找安全、可执行的恢复方向。

## 安装

```text
https://github.com/xiran1984/xrskill，安装其中的 xr-trauma-support
```

## 怎么用

```text
/xr-trauma-support 我知道应该开始，但一想到失败就会僵住并责备自己。
```

## 可以问什么

```text
/xr-trauma-support 过去的经历一直影响我，我该怎么办？
/xr-trauma-support 我总觉得只有对别人有用才值得被爱。
/xr-trauma-support 我明明处在安全环境里，还是会觉得别人想控制我。
/xr-trauma-support 以前做什么都没用，现在我也觉得行动无法改变结果。
/xr-trauma-support 我一直后悔当年的选择，无法停止责备自己。
```

它会按“创伤识别—情绪宽慰—解决方法”逐步对话。所有来源判断都只是允许用户否定的假设，不会把推测当成事实。

## 例子

问：`/xr-trauma-support 我一犯小错，就会自动觉得自己整个人都没有价值。`

答：

```text
听起来，真正压住你的可能不只是这次小错，而是“犯错就会被否定整个人”的旧警报。
如果你过去经常因小失误遭到羞辱，这种自动责备曾可能帮助你提前避免攻击；但它不等于现在的事实。

这个理解与你接近吗？
```

本 Skill 只提供创伤初筛与自助支持，不替代诊断或专业治疗。出现自伤、伤人或现实暴力危险时，应优先寻求现实中的紧急与专业支持。
