# 恢复路线与方法

## 路由

本文件仅在第三步读取。八个方向是检查地图，不是固定疗程；每次只选一个当前瓶颈和一个行动。

```text
现实危险仍在 → 环境安全、边界与外部支持
情绪明显过载 → 身体与情绪稳定
过去警报覆盖事实 → 区分过去与现在
旧保护反应接管 → 理解生存策略
绝对自我判断 → 更新旧信念
关系中不能保有自我 → 建立关系安全
愤怒、需求或拒绝被压制 → 恢复边界与欲望
人生只剩避免失败和外部评价 → 建立自主价值
已经理解但仍不行动 → 重新进入现实
```

## 八个恢复方向

### 1. 区分过去与现在

适用于小事触发巨大情绪、批评或遗漏引起强烈警报、反复出现来不及和无法补救的梦。分别确认过去发生过什么、现在实际发生什么、相同与不同之处。最小验证：指出一项当前安全证据和一个真实风险，而非笼统告诉自己“没事”。

### 2. 恢复可感知的安全

- 身体：支持规律睡眠、适量运动、饮食与医疗照顾、温和呼气、肌肉放松和现实定向；不宣称“重置神经系统”。
- 情绪：把愤怒、悲伤和恐惧当作信息，而非危险、命令或行动许可。
- 环境：检查持续攻击、羞辱、操控、住房和经济不稳；危险仍在时优先改变环境和增加支持。

### 3. 理解生存策略

把讨好、持续忙碌或逃避停下、控制或对抗、冻结或撤退视为可混合的保护反应，不是人格类型。先确认它过去保护了什么，再比较现在的收益与代价，不直接要求停止。

### 4. 更新旧信念

把抽象判断改成可检验预测，例如把“我不值得”改成“如果我表现普通，别人就一定抛弃我”。依次检查过去功能、当前事实、适用边界和现实代价，再由用户选择可信的条件规则。

行为实验必须低风险、可退出、可观察：写清旧预测、最小动作、实际结果和停止条件。现实危险仍在时不挑战警觉。

### 5. 建立关系安全

根据情况练习一个能力：表达需要、接受帮助、允许别人失望、分级验证信任、在亲密中保留边界和退出权。持续操控、羞辱或暴力关系优先安全，不预设值得修复。

### 6. 恢复愤怒、欲望与边界

愤怒可能提示边界，但不许可伤害；欲望是需要了解的信息，不等于必须满足；边界用于区分双方选择与责任。最小动作通常是一句具体表达，现实危险下不直接对抗。

### 7. 建立自主价值

从只避免失败、取悦别人和证明价值，转向用户认可的方向：想保护什么、创造什么、实践哪些品质。价值不是新的考核，不预设事业、婚姻、生育或影响力。

### 8. 重新进入现实

根据用户目标恢复关系、学习、工作、创造和承担可控风险；不以生产力衡量人的价值。选择一个小行动，用真实结果更新旧预测，不等待“完全疗愈”才生活。

## 特殊问题

- **习得性无助**：区分不可控、可影响、可直接控制；从成功率高的小动作恢复局部因果感，不承诺努力改变结构限制。
- **成瘾与合理化**：比较行为前理由、实际行为、短期奖励和长期代价；严重成瘾、危险戒断或过量风险转专业支持。
- **无意义苦难**：允许偶然、不公平和无意义；不强迫积极、成长或寻找命运安排。
- **长期后悔**：还原当时可知信息、资源和压力；区分责任、事后信息和偶然结果；能补救则行动，不可逆则哀悼并提炼一条未来规则。
- **阶层差距**：承认真实资源和容错率差距；区分结构限制与永久低价值，不承诺努力必然跨越阶层。

```text

最终目标：{用户确认的功能目标和完成标志}
已确认事实：{经历或来源未知、威胁、保护策略、旧预测、触发、代价、仍有效的保护作用}
现实约束：{当前安全、可用支持、用户边界}
当前瓶颈：{只选一个恢复方向，用生活语言}

要求：
1. 从目标倒推必要条件，只展开当前瓶颈。
2. 叶子节点须可执行或可观察，优先低风险、可退出的小实验。
3. 不诊断、恢复记忆、催眠、强迫宽恕或自行暴露；不降低对真实危险的警觉。
4. 不用生产力、关系或生育证明人的价值。
5. 输出最终目标、必要假设、条件树、优先路径、验证标准、停止条件和专业支持节点。
```

## 选择边界

- 安全不足时不做信念挑战；稳定不足时不做系统规划。
- 不把正常悲伤、压力、粗心、性格差异或生活选择自动解释成创伤。
- 反复噩梦、解离、成瘾、严重失眠、持续功能损害或自伤风险需要专业评估。
- 不拆解“彻底治愈”“删除记忆”或“永远不痛苦”。
